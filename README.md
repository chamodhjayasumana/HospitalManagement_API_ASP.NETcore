# 🏥 Hospital Management API – ASP.NET Core

This is a **Hospital Management System backend** built with **ASP.NET Core Web API**. It provides a RESTful API to manage hospital-related data including patients, doctors, appointments, and other clinical records.

---

## 📌 Features

- ✅ RESTful API with CRUD operations
- 👨‍⚕️ Manage patients, doctors, appointments, clinics, and more
- 🔐 Role-based authentication (if implemented)
- 📦 Entity Framework Core for database interaction
- 📝 Swagger API documentation
- 📁 Structured controller/service/repository architecture

---

## 🧰 Technologies Used

- ASP.NET Core 6 (or 7 depending on your version)
- Entity Framework Core
- SQL Server (LocalDb or SQL Server Express)
- AutoMapper
- Swagger (Swashbuckle)
- CORS Configuration
- LINQ for data querying
- Dependency Injection (built-in)
